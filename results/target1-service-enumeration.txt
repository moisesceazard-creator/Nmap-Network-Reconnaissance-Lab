Nmap Service and Version Enumeration
====================================

Target: 192.168.1.120
Command: nmap -sV -p 8000 192.168.1.120

Result
------

PORT     STATE SERVICE VERSION
8000/tcp open  http    SimpleHTTPServer 0.6 (Python 3.12.3)

Assessment
----------

TCP/8000 was identified as an open HTTP service running
SimpleHTTPServer 0.6 on Python 3.12.3.

The service was intentionally enabled within the controlled
laboratory environment for service enumeration and validation.

Security Relevance
------------------

The reachable HTTP service contributes to the network-facing
attack surface of the target. The scan confirms service exposure
but does not by itself establish a vulnerability or exploitability.

Validation
----------

The identified HTTP service was subsequently validated using:

curl -I http://192.168.1.120:8000

The service returned HTTP/1.0 200 OK and identified itself as
SimpleHTTP/0.6 running on Python 3.12.3.
